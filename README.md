# T50-Systems community defaults

This repository defines organization-wide default community health files for T50-Systems repositories.

GitHub uses these defaults for repositories that do not provide their own project-specific files.

## Included defaults

- `CODE_OF_CONDUCT.md` — expected behavior and enforcement baseline.
- `CONTRIBUTING.md` — contribution workflow and PR expectations.
- `SECURITY.md` — private vulnerability reporting policy.
- `SUPPORT.md` — support routing for bugs, features, questions, and security.
- `.github/ISSUE_TEMPLATE/*.yml` — default bug, feature, and task issue forms.
- `.github/pull_request_template.md` — default pull request checklist.

Project-specific files in a repository override these defaults when a project needs stricter or more detailed guidance.
