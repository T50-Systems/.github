# T50-Systems

T50-Systems builds focused software products, tooling, and automation systems.

## Working with our repositories

- Read each repository's README before opening issues or pull requests.
- Use the provided issue forms for bugs, features, and maintenance tasks.
- Follow the organization-wide contribution, security, support, and code-of-conduct defaults unless a repository provides more specific guidance.
- Never include secrets, tokens, private keys, customer data, or local session files in issues, pull requests, or commits.

## Security

Report vulnerabilities privately through the affected repository's Security tab when available. Do not disclose exploit details in public issues.
